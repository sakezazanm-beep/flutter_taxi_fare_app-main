# Taxi Fare Calculator

Flutter app for calculating a taxi fare from distance and traffic waiting time.

## Run

Install dependencies and run the app in Chrome:

```shell
flutter pub get
flutter run -d chrome
```

Windows desktop is also configured; building it requires Visual Studio with the
**Desktop development with C++** workload installed:

```shell
flutter run -d windows
```

## Taxi illustration

The taxi image supplied for this project is stored at `assets/taxi_icon.png`.
